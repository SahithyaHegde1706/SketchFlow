# SketchFlow 🎨
A collaborative, Excalidraw-inspired whiteboard built with Next.js, TypeScript, HTML Canvas, Socket.IO, and PostgreSQL.

## Features:-
- **Drawing Tools:** Freehand, shapes, arrows, text, and eraser.
- **Editing:** Select, move, resize, rotate, group, and duplicate elements.
- **Canvas:** Infinite-style workspace with pan, zoom, and grid.
- **Undo & Redo:** Easily manage drawing history.
- **Image & Text Editing:** Add images and customize text styling.
- **Export:** Download boards as PNG or SVG.
- **Real-Time Collaboration:** Shared drawing, live cursors, selections, and collaborator presence.
- **Persistent Boards:** Create, save, load, and share boards through URLs.
- **Themes:** Light and dark mode.

## Tech Stack:- 
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Canvas:** HTML Canvas API
- **Backend:** Node.js, Express, Socket.IO
- **Database:** PostgreSQL, Neon, Prisma ORM
- **Package Manager:** pnpm
